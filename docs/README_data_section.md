## 数据说明

本项目的核心结论依赖 A/B 实验的因果评估，而公开数据集中不存在"Agent 干预"和随机分流。因此采用 **"公开数据校准 + 仿真植入已知效应"** 的方案：

1. 用公开数据估计商家基线行为的分布（校准）；
2. 在仿真器中生成虚拟商家，并**植入已知的处理效应**；
3. 用分析流程（DID / CUPED / IV 等）检验能否还原该效应，以验证评估方法的有效性。

> ⚠️ 仿真结果只能说明**评估方法是否可靠**，不能直接代表真实业务中 Agent 的收益。真实收益需要在线上实验中验证。

### 数据来源

| 数据集 | 用途 | 获取方式 |
|---|---|---|
| 天池 O2O 优惠券使用预测（线下表） | 校准核销率、领券到核销转化、普通交易量、券力度分布 | 天池官网下载（需账号） |
| Yelp Open Dataset | 校准商家类别/城市/营业时间等属性分布，签到与评论的时间序列特征 | Yelp 官网申请下载 |

**原始数据不包含在本仓库中。** 请自行下载并遵守各数据集的使用条款（Yelp 数据面向学术、非商业用途；天池数据的授权条款请以官网为准）。数据放置路径见 `data/README.md`。

### 指标与数据覆盖

| 业务指标 | 天池 | Yelp | 仿真器中的处理 |
|---|---|---|---|
| 核销 | ✅ 可直接汇总 | ❌ | 由天池校准基线，仿真生成 |
| 到店交易 | ✅ 普通消费记录 | ⚠️ 签到/评论仅为热度代理 | 以天池为主，Yelp 辅助周期性 |
| 商家活跃度 | ❌ | ❌ | **完全仿真**（登录、策略采纳等），参数为假设 |
| 商家属性（品类、商圈、营业时间） | ❌ | ✅ | 由 Yelp 属性分布校准 |
| 曝光/点击漏斗 | ❌ | ❌ | 仿真，参数为假设 |
| 评分（护栏指标） | ❌ | ✅ 星级 | 由 Yelp 校准基线 |

### 仿真器参数对照

**A. 由公开数据估计的参数（校准）**

| 参数 | 来源 | 估计方式 |
|---|---|---|
| 商家核销量的分布（含长尾） | 天池 | 按商户汇总后拟合分布 |
| 领券→核销转化率及其随券力度的变化 | 天池 | 按折扣类型（折扣/满减）分组估计 |
| 普通交易量的周/月周期性 | 天池 | 时间序列分解 |
| 商家类别、城市、营业时间分布 | Yelp | 经验分布 |
| 签到/评论量的周期性与低热度商家占比 | Yelp | 经验分布 |

**B. 由研究者设定的参数（假设，需做敏感性分析）**

| 参数 | 说明 |
|---|---|
| 处理效应大小 | 例如核销提升的相对幅度，设置多档（含 0 效应用于检验假阳性） |
| 策略采纳率 | 实验组商家实际执行方案的比例，用于检验 ITT 与采纳者效应（CACE） |
| 同商圈溢出强度 | 实验组商家对邻近对照商家的挤出或带动 |
| 商家活跃度的生成过程 | 缺乏公开数据支撑，仅作过程指标 |
| 组间基线不平衡程度 | 用于检验协变量调整方法的稳健性 |

### 验证清单

- [ ] 0 效应情形下，假阳性率接近显著性水平
- [ ] 已知效应情形下，估计值的偏差与覆盖率达标
- [ ] 采纳率低于 100% 时，ITT 与 CACE 分别可还原
- [ ] 存在溢出时，分商圈整体分流 vs 商家级分流的偏差对比
- [ ] 先验功效分析：给定方差下达到目标功效所需样本量

### 局限性

- 天池数据为 2016 年的国内线下场景，Yelp 为美国数据，二者仅用于校准分布形状，不代表当前目标市场。
- 商家活跃度、曝光点击等指标无公开数据支撑，相关参数均为假设。
- 仿真无法替代线上随机实验。
